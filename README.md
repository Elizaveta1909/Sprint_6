# Автотесты для сервиса Яндекс Самокат

Основа для написания автотестов — фреймворк pytest, selenium

Команда для запуска — pytest -v.

# Написаны тесты на 3 функциональности:

1. test_login.py - проверка автороизации
2. test_questions.py - проверка выпадающего списока в разделе «Вопросы о важном». 
3. test_rent_scooter.py - проверка заказа самоката
